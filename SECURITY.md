# Security reports

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/oraclevs/nib_website/security/advisories/new). Include the affected route or workflow, reproduction steps and expected impact. Do not include live credentials or customer data.

Pull-request checks use public documentation only. Private dependency access and deployment credentials belong in protected GitHub environments. Production documentation sync is disabled until the maintainer activates it after a verified preview. See [documentation delivery](docs/DOCS_SYNC.md).
